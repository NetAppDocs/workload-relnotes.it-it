[[database-workloads]]
=== Workload dei database



==== Configurazioni del database incluse nella dashboard ben strutturata

La dashboard ben progettata ora include suggerimenti per le configurazioni del database, consentendoti di valutare e ottimizzare la tua configurazione in base alle migliori pratiche. Le prime configurazioni incluse nella dashboard sono:

* Tiering dei dati freddi
* Efficienze dello storage
* policy di Snapshot
* margine di capacità SSD
* Gestione dello spazio del dispositivo a blocchi
* Tipo OS
* Abbina il tipo di sistema operativo del dispositivo a blocchi all'host
* Dispositivi a blocchi inattivi (LUNs)
* Posizionamento dei file di dati (.mdf)
* Posizionamento dei file di registro (.ldf)
* Stato I/O multipath
* Timeout Multipath I/O
* Quorum del cluster
* Ridimensionamento delle risorse di calcolo


Seleziona il menu principale nella console di Workload Factory, quindi seleziona *Well-architected* per trovare la dashboard well-architected.

image:well-architected-menu-option.png["Opzione di menu ben strutturata nella console di NetApp Workload Factory"]



[[vmware-workloads]]
=== Workload VMware



==== Supporto per le istanze i7i.metal-24xl e i7i.metal-48xl nel calcolatore TCO di EVS

Il calcolatore TCO di EVS ora supporta le istanze EC2 AWS i7i.metal-24xl e i7i.metal-48xl come host del cluster. Rispetto alle configurazioni i4i.metal, le istanze i7i.metal-24xl riducono il costo iniziale di EVS di circa il 33% per il calcolo e del 25% per lo storage vSAN.

Il calcolatore confronta tutti i tipi di istanza e seleziona automaticamente l'opzione più economica. Una nuova sezione di confronto mostra le configurazioni degli host EVS affiancate, semplificando la scelta della configurazione più adatta alle tue esigenze.

link:https://docs.netapp.com/us-en/workload-vmware/calculate-evs-savings.html["Calcola il risparmio stimato per EVS"]

==== Aggiornamenti della dashboard personalizzata

Le dashboard personalizzate ora semplificano la gestione del tuo lavoro.

Puoi modificare le dashboard direttamente dal catalogo, incluse metriche, grafici e intervalli di tempo.

Quando modifichi una dashboard, Workload Factory riapre la chat con le tue richieste e i tuoi messaggi precedenti. Puoi quindi aggiornare la dashboard, salvare le modifiche o ripristinare la versione precedente.

Solo chi ha creato la dashboard può modificarla. Durante la modifica, gli altri utenti non potranno visualizzare le modifiche finché non le salverai.

Il catalogo delle dashboard ora include più filtri per aiutarti a trovare rapidamente le dashboard in base alla categoria e allo stato.

Se il tuo amministratore disabilita le funzionalità di AI o viene raggiunto il limite di credito mensile, non puoi più creare o modificare le dashboard.

[[amazon-fsx-for-netapp-ontap]]
=== Amazon FSX per NetApp ONTAP



==== Rilevamento esteso dei tag dei carichi di lavoro per i servizi AWS

Workload Factory ora rileva più servizi AWS per l'assegnazione di tag ai carichi di lavoro, ampliando il supporto per le risorse che possono essere etichettate. Ora può individuare le risorse Amazon EKS e Amazon WorkSpaces e includerle nel sistema di etichettatura, rendendole disponibili per l'assegnazione di tag.



==== Miglioramenti al dashboard dei costi

La dashboard dei costi ora include una sezione di riepilogo esecutivo dei costi che fornisce una panoramica delle spese della tua organizzazione, aiutandoti a comprendere e gestire rapidamente i costi. Ask Me, l'assistente AI di Workload Factory, può fornire ulteriori approfondimenti e raccomandazioni in base ai tuoi dati sui costi. Puoi interagire con Ask Me per ottenere spiegazioni dettagliate e suggerimenti per ottimizzare i tuoi costi.

Inoltre, puoi filtrare i dati relativi ai costi in base a uno o più file system e a uno o più volumi all'interno di un file system. Quando applichi i filtri, Workload Factory visualizza:

* Costo totale stimato al mese
* Costo stimato per GiB/mese
* Ripartizione dettagliata dei costi per servizio


Tutte le informazioni sui costi provengono direttamente dall'API AWS Cost Explorer, ad eccezione dell'allocazione dei costi a livello di file system e di volume; Workload Factory stima l'allocazione dei costi a livello di file system e di volume.



==== Accesso alla dashboard Well-Architected

Puoi accedere alla dashboard well-architected dal menu principale nella console di Workload Factory e dall'interno di un file system. Per trovare la dashboard well-architected dal menu principale, seleziona il menu principale e quindi seleziona *Well-architected*.

image:well-architected-menu-option.png["Opzione di menu ben strutturata nella console di NetApp Workload Factory"]



==== Nuove raccomandazioni nell'analisi well-architected

Workload Factory ora include le seguenti configurazioni nell'analisi dell'architettura ottimale per i file system FSx for ONTAP:

* *Configurazione della gestione dello spazio dei volumi*: consiglia di abilitare la gestione coordinata dello spazio dei volumi per i volumi FSx for ONTAP.
* *Integrazione di FSx con AWS MGN*: ti consiglia di applicare la configurazione di preparazione AWS MGN richiesta ai file system FSx for ONTAP selezionati.


link:https://docs.netapp.com/us-en/workload-fsx-ontap/configuration-analysis.html["Scopri di più sulle best practice consigliate per i tuoi file system FSx per ONTAP."]



==== Miglioramenti all'esploratore di volumi

Volumes explorer è un punto centrale nella console di Workload Factory in cui puoi visualizzare e gestire tutti i tuoi volumi in diversi file system. Fornisce informazioni dettagliate su ciascun volume, incluse prestazioni, utilizzo e stato di protezione. I miglioramenti di questa versione includono la selezione del carico di lavoro, la visualizzazione della latenza del volume e lo stato ARP/AI per i volumi.



===== Volumes explorer supporta la selezione del carico di lavoro

Workload Factory seleziona un carico di lavoro per impostazione predefinita in base alle caratteristiche del volume e ai suoi modelli di utilizzo. Ora puoi modificare il carico di lavoro per uno o più volumi da Volumes explorer.



===== Volumes explorer visualizza la latenza del volume

Volumes explorer visualizza lo stato della latenza del volume con i seguenti stati: non configurato, entro la soglia e superata. Questi stati ti aiutano a individuare e risolvere i colli di bottiglia delle prestazioni a livello di volume.



===== Esplora volumi visualizza lo stato ARP/AI per i volumi in tutti i file system

La schermata di esplorazione dei volumi include ora una scheda con lo stato di NetApp Autonomous Ransomware Protection with AI (ARP/AI) per i volumi su tutti i tuoi file system. La scheda mostra il numero di volumi protetti e indica se alcuni volumi sono a rischio. Dalla scheda, puoi selezionare *Analyze attacks* per analizzare le potenziali minacce ransomware e intraprendere le azioni appropriate per proteggere i tuoi dati.

image:volumes-explorer-arp-ai-card.png["Lo screenshot mostra una nuova scheda nella schermata Esplora volumi che visualizza lo stato ARP/AI per i volumi in tutti i file system. La scheda indica il numero di volumi protetti e gli eventuali volumi a rischio. Puoi selezionare la voce Analyze attacks per esaminare gli attacchi sospetti e intraprendere le azioni appropriate per proteggere i tuoi dati."]

link:https://docs.netapp.com/us-en/workload-fsx-ontap/ransomware-protection.html["Scopri di più sulla protezione dal ransomware."]



==== Notifica via email per relazioni di replica non integre

Quando lo stato di una relazione di replica è *non integro*, Workload Factory invia una notifica via e-mail ogni 24 ore finché la relazione rimane non integra. Le notifiche di promemoria si interrompono quando la relazione torna a uno stato integro.



==== Supporto per credenziali ONTAP limitate per AIOps

Workload Factory supporta due tipi di credenziali ONTAP per un file system FSx for ONTAP: primarie e con restrizioni. Per impostazione predefinita, un file system utilizza le credenziali ONTAP primarie. Utilizziamo le credenziali con restrizioni solo per le operazioni di AI (AIOps) come Rule builder, dashboard personalizzate e Ask Me, il nostro assistente AI. Ora puoi aggiungere le tue credenziali, usando un nome utente e una password o un ARN segreto, per limitare l'accesso alle funzionalità AIOps.

link:https://docs.netapp.com/us-en/workload-fsx-ontap/manage-file-system-settings.html["Gestisci le credenziali ONTAP per un file system FSx for ONTAP"]



==== Selezione del carico di lavoro durante la creazione del volume

Workload Factory ora include un campo *Workloads* nella creazione dei volumi, in modo che tu possa selezionare il carico di lavoro da associare al volume. Questo garantisce che il volume sia ottimizzato per il carico di lavoro previsto fin dal momento della creazione.

link:https://docs.netapp.com/us-en/workload-fsx-ontap/create-volume.html["Crea un volume nella console di Workload Factory"]



==== Miglioramento della modalità di scrittura di FlexCache

Workload Factory ora riconosce la modalità di scrittura preferita di FlexCache per i volumi e consiglia di modificarla, se necessario, per ottimizzare le prestazioni.



==== Supporto alla documentazione dei collegamenti

Tutta la documentazione relativa ai collegamenti è ora inclusa nella documentazione di configurazione e amministrazione di Workload Factory. Puoi comunque fare riferimento alla link:https://docs.netapp.com/us-en/workload-fsx-ontap/links-overview.html["Scopri i collegamenti di NetApp Workload Factory"]documentazione di Workload Factory FSx for ONTAP e trovare i collegamenti alle pagine pertinenti nella documentazione di configurazione e amministrazione.

link:https://docs.netapp.com/us-en/workload-setup-admin/create-link.html["Scopri di più sulla configurazione dei collegamenti nella console di Workload Factory."^]



==== Individuazione della relazione host-storage tra regioni diverse

Workload Factory ora supporta l'individuazione delle connessioni tra host e storage in più regioni AWS come parte del servizio di etichettatura dei carichi di lavoro. Può identificare e collegare host e risorse di storage tra regioni, inclusa la mappatura degli indirizzi IP tra regioni, in modo che le relazioni tra host e storage vengano etichettate e classificate correttamente.



==== Maggiore precisione nell'identificazione del workload e dell'host

Workload Factory ora identifica e classifica con maggiore precisione i carichi di lavoro e gli host nel servizio di tagging dei carichi di lavoro. I metodi di rilevamento aggiornati riducono gli errori di classificazione e forniscono risultati di tagging e classificazione più accurati.



==== Maggiore visibilità del file system nell'interfaccia

Workload Factory ora ti offre una visione più chiara dei file system nell'interfaccia. Puoi visualizzare le tendenze di utilizzo della capacità SSD e del throughput, i riepiloghi dei carichi di lavoro e informazioni dettagliate sulla configurazione direttamente dalla panoramica del file system. ==== Agenti AI per Workload Factory

Workload Factory AIOps utilizza l'intelligenza artificiale per analizzare il tuo ambiente e consigliare miglioramenti. Se approvi, può anche eseguire azioni utilizzando le credenziali e le autorizzazioni che hai configurato. Gli agenti AI analizzano il tuo ambiente, aiutandoti a individuare i rischi, migliorare i workload e risolvere i problemi in Workload Factory e Slack.

Accedi agli agenti IA nella nuova sezione *Esplora agenti* in Ask Me. Per impostazione predefinita, gli agenti vengono eseguiti in modalità di sola lettura e forniscono raccomandazioni e analisi.

Usa *Impostazioni agenti* per controllare come funzionano gli agenti. Puoi:

* Scegli la modalità di sola lettura o di lettura/scrittura
* Seleziona le credenziali che gli agenti possono utilizzare
* Aggiungi istruzioni personalizzate
* Regola il livello di dettaglio delle risposte


Questi controlli aggiuntivi ti offrono maggiore visibilità e supervisione. In modalità di lettura/scrittura, gli agenti devono ottenere la tua approvazione prima di apportare modifiche ad AWS, ONTAP o alle API supportate. Puoi anche scegliere il livello di dettaglio da visualizzare nelle risposte, incluse le informazioni sul ragionamento dell'agente e, in Slack, la sua attività con gli strumenti.

Gli agenti supportano anche ambienti multi-account e semplificano la configurazione. Un singolo agente può operare in modo sicuro su più account AWS utilizzando credenziali diverse.

link:https://docs.netapp.com/us-en/workload-setup-admin/learn-agent.html["Scopri di più sugli agenti di intelligenza artificiale"]

link:https://docs.netapp.com/us-en/workload-setup-admin/manage-agent-settings.html["Gestisci le impostazioni degli agenti"]



==== Attività programmate in Ask Me

Ora puoi personalizzare un prompt nella chat di Ask Me per creare attività pianificate. Usa le attività pianificate per chiedere ad Ask Me di eseguire controlli ricorrenti e inviare aggiornamenti in chat in base alla pianificazione che definisci.

Esempi di richieste:

* Verifica ogni ora lo stato di salute e il ciclo di vita di tutti i file system FSx for NetApp ONTAP per individuare tempestivamente eventuali problemi.
* Elenca ogni ora tutti i file system AWS FSx accessibili per mantenere un inventario aggiornato.


link:https://docs.netapp.com/us-en/workload-setup-admin/workload-factory-overview.html#features["Scopri di più su Ask Me"]



==== Supporto per lo storage in Ask Me

Ask Me ora supporta FSx per ONTAP e Google Cloud NetApp Volumes. Usa la stessa esperienza di chat per ottenere risposte e approfondimenti in tutti gli ambienti di storage supportati.

link:https://docs.netapp.com/us-en/workload-setup-admin/workload-factory-overview.html#features["Scopri di più su Ask Me"]



==== Aggiornamento delle notifiche

Le notifiche di NetApp Console sono ora abilitate per impostazione predefinita. Gli utenti di NetApp Console riceveranno automaticamente le notifiche di Workload Factory senza ulteriori configurazioni.

link:https://docs.netapp.com/us-en/workload-setup-admin/configure-notifications.html["Notifiche di Workload Factory"]



==== Email di notifica della creazione del collegamento

Workload Factory ora ti ricorda di completare l'associazione del collegamento dopo aver aggiunto correttamente le credenziali. Sebbene le credenziali consentano il rilevamento delle risorse, le funzionalità avanzate di ONTAP richiedono l'associazione del collegamento con i file system rilevati. Riceverai la notifica via e-mail una volta a settimana, il lunedì. Dopo aver completato l'associazione del collegamento, le notifiche si interrompono.



==== Notifiche sulla versione di Lambda link e guida all'aggiornamento

Workload Factory ora ti avvisa quando un collegamento Lambda non utilizza l'immagine più recente disponibile. Se gli aggiornamenti automatici non sono supportati per un collegamento, la notifica indica quando è disponibile una versione più recente.

Puoi visualizzare le istruzioni di aggiornamento dalla pagina Collegamenti. Le istruzioni spiegano come aggiornare manualmente l'immagine del collegamento Lambda e abilitare gli aggiornamenti automatici quando sono disponibili. Mantenere i collegamenti aggiornati ti consente di accedere alle funzionalità più recenti, risolvere i problemi noti e applicare gli aggiornamenti di sicurezza più recenti.

Ricevi anche un avviso nella dashboard di FSx per ONTAP quando è disponibile una versione più recente del collegamento per un collegamento che non supporta gli aggiornamenti automatici.
