=== Supporto per più file system per una singola istanza

Workload Factory for Databases supporta più file system per una singola istanza di Microsoft SQL Server. Puoi registrare più file system in un'istanza di SQL Server e risolvere contemporaneamente un problema di configurazione per più file system in un'istanza di SQL Server.
